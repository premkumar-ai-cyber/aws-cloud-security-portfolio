# AWS Account Setup

## Project Overview

This project demonstrates how to securely set up a new AWS account by following AWS security best practices. The account was configured with Multi-Factor Authentication (MFA), billing alerts, and an IAM administrator user to provide a secure foundation for future AWS projects.

---

## Objectives

- Create an AWS account
- Configure billing information
- Enable Free Tier usage alerts
- Enable Multi-Factor Authentication (MFA)
- Create an IAM Administrator user
- Follow AWS security best practices

---

## AWS Services Used

- AWS Identity and Access Management (IAM)
- AWS Billing
- AWS Free Tier
- AWS Management Console

---

## Implementation Steps

1. Created a new AWS account.
2. Verified email address and phone number.
3. Configured billing information.
4. Selected the Basic Support Plan.
5. Enabled AWS Free Tier usage alerts.
6. Enabled Multi-Factor Authentication (MFA) for the root user.
7. Created an IAM Administrator user.
8. Signed in using the IAM user instead of the root account.

---

## Security Best Practices Implemented

- Enabled Multi-Factor Authentication (MFA)
- Avoided using the root account for daily activities
- Created an IAM Administrator user
- Enabled Free Tier billing alerts
- Used a strong password for the root user

---

## Project Outcome

Successfully created and secured an AWS account following AWS best practices. The account is now ready for deploying cloud resources and performing future AWS projects securely.
